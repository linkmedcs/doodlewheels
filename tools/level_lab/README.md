# 电脑端关卡实验室

支持当前工程的全部 60 关：原版 1～45 和扩展 46～60。直接读取 `decompiled/apktool/assets/lvs/` 的 `.dwl` 文件，使用游戏原有图集和中文提示，提供地图预览、可视化设计与近似试玩。普通试玩不写入关卡；可视化编辑器只有点击“保存到工程”才写入地图。不修改存档或 APK。

## 启动

双击项目根目录的 `启动关卡实验室.command`，然后打开 http://127.0.0.1:8765 。首次缺少依赖时，启动器会安装到项目 `build/level-lab/python/`，不修改系统 Python。

也可在项目根目录运行：

```sh
/usr/bin/python3 -m pip install --target build/level-lab/python -r tools/level_lab/requirements.txt
/usr/bin/python3 tools/level_lab/server.py
```

当前依赖为 Box2D 2.3.10 与 Lupa 2.6，已在本机 Python 3.9 / Apple Silicon 验证。端口冲突可在服务器命令后加 `--port 8766`。终端按 Ctrl+C 关闭。

## 操作

- 下拉选择任意 1～60 关，也可用上一关、下一关切换。
- 左右方向键或 A、D 驾驶；空格暂停；R 重置并重新读取磁盘地图。
- 单步推进 1/60 秒；拖动平移，滚轮缩放；支持地图总览与跟随车辆。
- 可切换原游戏素材或几何绘图。修改 `.dwl` 后点击重置即可生效。

## 可视化设计

点击实验室的“可视化设计关卡”，或打开 http://127.0.0.1:8765/editor?level=48 。全部 60 关均可编辑。

- 直接拖动物体改变初始位置，右侧调整角度、原版木板素材、密度、摩擦和弹性。密度为 0 表示固定。
- Shift 点选多个物体，或 Shift 在空白处拖出框选区域；可整体移动、绕组合中心旋转。空白处拖动平移，滚轮以鼠标位置缩放；可开启 10 像素网格对齐。
- 素材库仅保留 10 种基础物理形状和 1 个触发开关，不再列出按物理参数重复的预设或联动跷跷板等复杂组合。货球、车辆、车轮、星星和菜单装饰不在素材库中；地图现有任务对象仍可拖动调整。
- 选中建筑素材，在右侧直接设置弹性、摩擦、密度（0 为固定，大于 0 为动态物体），以及碰撞形状和感应体。长度通过选择不同尺寸的木板实现。例如选迷你木板，将弹性设为 1.5，即可制作第 24 关的弹性板。
- 颜色可用取色器或十六进制 `#RRGGBB` 设置，实时显示在设计画布和草稿试玩中，支持撤销和恢复原色。保存时生成原生 `color(find(...),r,g,b)` 指令，在原脚本初始化后执行；颜色记录在编辑器注释元数据中，不新增原生不支持的 XML 属性。恢复原色会撤除编辑器颜色覆盖，保留原关卡 Lua 的染色。颜色设置适用于有唯一标识的建筑物体。
- 开关可设置移除挡板的目标和 0～60 秒延迟。素材库已移除组合模板；已有地图和旧草稿中的机关连接继续保留。
- 右侧复制、删除素材；⌘Z 撤销，⌘⇧Z 重做，方向键微调（Shift 加速）。货球、车辆和目标必须保留；后端阻止删除原版 Lua 脚本引用的物体和破坏新组合的连接。生成的机关用原生 `create26`、`create23`、`createjoint10`、`active10`、`find`、`remove` 接口，追加到标记明确的 Lua 区块；原脚本保留，保存重载不会重复添加初始化。编辑器元数据存于 XML 注释，不增加原生不识别的地图节点。
- “螺旋轨道生成器”可调整内外半径、圈数、通道宽度和方向，先显示轮廓，再放入由原版短板组成的双侧轨道。几何轮廓不代表必然能通关；轨道连接、动能、出射角仍需试玩调整。
- 点击“试玩草稿”直接测试尚未保存的布局，并显示小球轨迹；空格暂停，R 重试。“返回设计”回到试玩前的初始布局，不把模拟后的物体位置写回地图。
- 浏览器自动保留每关草稿，也可“导出草稿”为 JSON。导出用于留档；目前不支持导入 JSON。
- “保存到工程”覆盖当前关卡 `.dwl`，并先在 `build/level-lab/backups/` 保存带时间戳的原始文件。保存保留 XML 注释、CDATA、Lua 和非编辑器节点；工程文件被其他工具更新时会阻止旧草稿覆盖，需重新载入。
- 编辑器仍使用电脑近似物理；保存后需重新构建 APK 才会进入安卓游戏，不会自动打包。

验证编辑器（所有实际写入测试都使用临时地图，不覆盖工程关卡）：

```sh
/usr/bin/python3 tools/level_lab/check_editor.py
/usr/bin/python3 tools/level_lab/check_materials.py
```

第 48 关“圆弧轨道”目前仍为设计草稿，已经可以在编辑器中查看和调整；尚未通过完整通关验证，不应视为已完成关卡。

## 模拟范围

服务器使用 Box2D 重建简化车辆与物体，车辆尺寸、扭矩和速度阈值沿用此前模拟参数；执行关卡 Lua 初始化和开关函数，支持颜色、透明度及延时移除。Lua 标准 I/O 和系统模块禁用。

该工具没有运行 Android APK 或 `libgame.so`，渲染和碰撞、摩擦、关卡完成判定可能与原游戏不同。开关按距离触发，货球进入目标 32 像素范围判定到达。第 10、43 关升降台采用近似直线运动，第 23 关联动机构采用近似铰链。第 26、47 关的链条按照原生 `create26` 的绳索约束重建，车辆和接触计算仍有差异；页面会列出这些限制。Lua 随机着色简化为固定配色。

全 60 关已通过加载、混合方向物理步进及有限数值检查，17 个开关均执行了对应 Lua 动作。这些检查不证明各关已被实际通关，也不取代手机测试。

第 46 关已替换为“借重弹射”：先向右把小球送上跷跷板左端，再向左回到开关，触发后松开方向键，托石板在 3 秒后撤除。右端落下的大球将小球翘向左上方终点平台。大球保持原始高度，跷跷板初始左低右高、倾角 25°，上方飞行空间已清空。支点沿板向右移动 20 像素，让左端有更大的运动幅度，改善原先弹射偏短的问题。

试玩时可以从重置开始，按住右键约 1.5 秒，再按住左键直到触发开关，随后松手等待弹射。电脑模拟中，向右持续约 1.33～1.92 秒的 8 组操作都能通关；过早回头会送球不到位，过晚可能冲出平台。失败后按 R 重试。

本关只使用原版素材和 `find`、`color`、`remove` 接口，弹射来自物理碰撞。验证覆盖静置稳定性、真实驾驶触发开关、3 秒延时释放、64 组不同车速及刹车位置的完整通关、8 组简单按键操作的完整通关、4 组失时失败和重置。所有通关测试都检查实际到达终点，未瞬移小球或施加额外弹射力。这些结果来自电脑近似模拟，仍需在手机上确认原生物理表现：

```sh
/usr/bin/python3 tools/level_lab/check_level46.py
```

第 47 关已替换为“链摆渡球”：两条由原版短板和小连接体组成的链条悬挂同一块吊台，在重力下往返。地图虽然将链节标为 `isSensor=true`，原生 `GameBody::init`（0xa31c8）却将 fixture 的传感器位清零，手机上链节仍会挡住球和车辆。实验室现在对 `create26` 引用的刚体应用同样的实体碰撞；其他传感器保持原状。

当前初始摆角为 22°（原为 14°），静置模拟中吊台的左右往返跨度约 299 像素（原约 194）。右岸和星星整体向右移 80、向上移 40 像素，两岸间隔由约 350 加宽到约 430 像素；同时调整悬挂位置和吊台高度，保持左岸能够送球登台。

原先等待约 5 秒、向右推球再刹车的路线，以及此前 35 组成功记录，使用了可穿透的链条，已失效。修正后该路线出现球与链条的真实碰撞并失败，不能再作为手机可通关的依据。针对性检查验证球与整车都会被链板挡住，第 26、47 关引用的链节均为实体，绳索长度参数保持不变。

第 47 关保持完整悬挂结构，不设断链按钮或释放逻辑，链条实体碰撞修复保留。

电脑端 `create26` 实现已根据 `libgame.so` 的 `lua_v26_create`（地址 `0xa6140`）修正：每次创建两条 `b2RopeJoint`，最大长度 0.6 米，短板局部锚点为 ±1.3 米，连接体锚点在局部质心，连接刚体之间不碰撞。原先“中点铰链”模拟已移除。此修正同时影响第 26 关在实验室中的预览，不改动其地图或原生库。第 47 关仍需手机验证。

```sh
/usr/bin/python3 tools/level_lab/check_level47.py
```

验证命令：

```sh
/usr/bin/python3 tools/level_lab/check_levels.py
```

服务仅监听 127.0.0.1；最多保留 16 个独立浏览器模拟会话。工具和依赖不进入 APK。

## 第 49 关：双跳接力

第 49 关已替换为左侧平地接 8° 下坡、中下方红色弹性板、右侧接球与推球平台。球与车依次触板弹起，落在右岸后继续驾驶推球至远端星星。弹性板使用原版长木板，密度 0、摩擦 0、弹性 1.2；脚本仅染色，不施加力或瞬移。

先从重置开始持续按右键。电脑近似模拟已有 4 条成功路线，包含落地后短暂松开油门再继续的操作；检查了球先弹、车后弹、两者落到右岸和车辆最终推球。此版本保留时机与速度造成失败的可能，不保证每次成功；安卓原生效果待手机试玩。验证：`/usr/bin/python3 tools/level_lab/check_level49.py`。

## 第 50 关：石雨升梯

当前为重新设计用的最简草稿：上方保留料斗、可撤底板和 30 块高摩擦小石子；下方只有一块固定平板和一个放石按钮。全部电梯、锚点、限位、旧道路、斜坡、闸门及自动升降联动均已删除。

小车、货球和星星移到下方平板，作为后续设计的基础对象。小车触发唯一按钮后，立即撤掉料斗底板，石子自然下落；脚本不再控制其他机关。此版本仅提供编辑起点，不代表已经完成通关设计，本次未做通关测试或打包 APK。
